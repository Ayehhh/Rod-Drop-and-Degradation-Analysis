Reciprocating Compressor Piston Rod Clearance Prognostic Analysis
-----------------------------------------------------------------
This script performs non-linear statistical regression modeling on rod drop/wear
data to project exact breach dates for Bently Nevada 3500 alarm limits (L / LL)
and OEM minimum allowable clearance thresholds.

Outputs:
  1. Professional Excel Prognostic Report with embedded calculations and conditional formatting
  2. High-resolution Prognostic Trend Plot (PNG image)
